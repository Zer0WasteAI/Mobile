# 🧩 ZER0 WASTE AI - FEATURE MODULES GUIDE\n\n## 📋 **COMPLETE FEATURE BREAKDOWN**\n\nThis document provides detailed information about each feature module in the ZER0 Waste AI application.\n\n---\n\n## 🔐 **1. AUTHENTICATION MODULE**\n\n**Location:** `lib/features/auth/`\n\n### **PURPOSE:**\nHandles user authentication, registration, and initial preference setup.\n\n### **KEY SCREENS:**\n- `LoginScreen` - User login with email/password\n- `RegisterScreen` - New user registration\n- `ForgotPasswordScreen` - Password recovery\n- `EmailVerificationScreen` - Email confirmation\n- `AuthTransitionScreen` - Loading state during auth\n\n### **KEY PROVIDERS:**\n```dart\n// Main authentication state\nfinal authStateProvider = StreamProvider<User?>\nfinal authProvider = StateNotifierProvider<AuthNotifier, AuthState>\n\n// Login form management\nfinal loginProvider = StateNotifierProvider<LoginNotifier, LoginState>\n\n// Registration flow\nfinal registerProvider = StateNotifierProvider<RegisterNotifier, RegisterState>\n\n// Password recovery\nfinal forgotPasswordProvider = StateNotifierProvider<ForgotPasswordNotifier, ForgotPasswordState>\n```\n\n### **KEY WIDGETS:**\n- `LoginForm` - Email/password input form\n- `RegisterForm` - Registration form with validation\n- `SocialButtonsRow` - Google/Apple sign-in buttons\n- `CustomTextField` - Styled input fields\n- `AnimatedLogo` - Animated app logo\n- `EmailVerificationDialog` - Email confirmation modal\n\n### **AUTHENTICATION FLOW:**\n1. User enters credentials\n2. Firebase authentication\n3. Backend JWT token exchange\n4. User preference setup (if first time)\n5. Redirect to main app\n\n---\n\n## 🏠 **2. HOME MODULE**\n\n**Location:** `lib/features/home/`\n\n### **PURPOSE:**\nMain dashboard showing overview of inventory, recipes, and environmental impact.\n\n### **KEY SCREENS:**\n- `HomeScreen` - Main dashboard with widgets\n\n### **KEY WIDGETS:**\n```dart\n// Dashboard components\nWelcomeHeader              // Personalized greeting\nInventorySummaryCard       // Inventory overview\nImpactSummaryCard         // Environmental metrics\nQuickActionsWidget        // Fast access buttons\nRecipeSuggestions         // AI recipe recommendations\nMotivationalCard          // Engagement content\nDailyPlannerWidget        // Today's meal plan\n```\n\n### **DASHBOARD LAYOUT:**\n```\n┌─────────────────────────┐\n│ Welcome Header          │\n├─────────────────────────┤\n│ Quick Actions (4 btns)  │\n├─────────────────────────┤\n│ Inventory Summary       │\n├─────────────────────────┤\n│ Recipe Suggestions      │\n├─────────────────────────┤\n│ Impact Summary          │\n├─────────────────────────┤\n│ Daily Planner           │\n├─────────────────────────┤\n│ Motivational Card       │\n└─────────────────────────┘\n```\n\n---\n\n## 📦 **3. INVENTORY MODULE**\n\n**Location:** `lib/features/inventory/`\n\n### **PURPOSE:**\nManage food inventory with expiration tracking and consumption monitoring.\n\n### **KEY SCREENS:**\n- `InventoryScreen` - Main inventory list\n- `AddInventoryItemScreen` - Add new items\n- `IngredientDetailScreen` - Detailed ingredient view\n- `FoodDetailScreen` - Detailed food item view\n- `FoodConsumedScreen` - Mark items as consumed\n\n### **KEY PROVIDERS:**\n```dart\n// Main inventory state\nfinal inventoryProvider = StateNotifierProvider<InventoryNotifier, InventoryState>\n\n// Backend operations\nfinal inventoryBackendProvider = Provider<InventoryBackendProvider>\n\n// UI state management\nfinal inventoryProviderConfig = Provider<InventoryProviderConfig>\n```\n\n### **KEY WIDGETS:**\n```dart\n// List and display\nInventoryItemCard              // Individual item display\nNutritionInfoChip             // Nutritional information\n\n// Filtering and sorting\nInventoryFilterBottomSheet     // Main filter modal\nExpirationFilterBottomSheet    // Filter by expiration\nStorageFilterBottomSheet       // Filter by storage type\n\n// Actions\nMarkConsumedDialog            // Consumption tracking\nExpiredItemActionsBottomSheet // Handle expired items\n```\n\n### **INVENTORY FEATURES:**\n- **Item Management** - Add, edit, delete items\n- **Expiration Tracking** - Visual indicators for expiry status\n- **Quantity Management** - Track amounts and units\n- **Storage Categories** - Fridge, pantry, freezer organization\n- **Consumption Tracking** - Mark items as used\n- **Smart Filtering** - By expiration, category, storage type\n\n### **ITEM CATEGORIES:**\n```dart\nenum ItemCategory {\n  ingredient,    // Raw ingredients\n  food,         // Prepared foods\n  beverage,     // Drinks\n  snack,        // Snack items\n}\n\nenum StorageType {\n  fridge,       // Refrigerated items\n  freezer,      // Frozen items\n  pantry,       // Room temperature\n  counter,      // Fresh produce\n}\n\nenum ExpirationStatus {\n  fresh,        // More than 3 days\n  expiringSoon, // 1-3 days\n  expired,      // Past expiration\n}\n```\n\n---\n\n## 🍳 **4. RECIPES MODULE**\n\n**Location:** `lib/features/recipes/`\n\n### **PURPOSE:**\nAI-powered recipe generation, management, and cooking assistance.\n\n### **KEY SCREENS:**\n- `RecipeScreen` - Main recipe hub (explore/smart modes)\n- `AIRecipeGenerationScreen` - Smart recipes from inventory\n- **Custom Generation** - Specify ingredients and preferences\n- **Recipe Library** - Browse all available recipes\n- **Favorites** - Save preferred recipes\n- **Cooking Mode** - Step-by-step instructions\n- **Personalization** - Based on dietary preferences\n- **Environmental Impact** - Recipe sustainability metrics\n\n---\n\n## 🤖 **5. RECOGNITION MODULE**\n\n**Location:** `lib/features/recognition/`\n\n### **PURPOSE:**\nAI-powered food and ingredient recognition from camera images.\n\n### **KEY SCREENS:**\n- `SimplifiedRecognitionScreen` - Ingredient recognition\n- `SimplifiedFoodRecognitionScreen` - Food recognition\n- `CameraRecognitionPage` - Camera interface\n\n### **KEY PROVIDERS:**\n```dart\n// Recognition processing\nfinal recognitionProvider = StateNotifierProvider<RecognitionNotifier, RecognitionState>\nfinal simplifiedRecognitionProvider = StateNotifierProvider<SimplifiedRecognitionNotifier, SimplifiedRecognitionState>\nfinal simplifiedFoodRecognitionProvider = StateNotifierProvider<SimplifiedFoodRecognitionNotifier, SimplifiedFoodRecognitionState>\n```\n\n### **KEY WIDGETS:**\n- `AllergyAlertWidget` - Allergy warnings for recognized items\n\n### **RECOGNITION FEATURES:**\n- **Ingredient Recognition** - Identify raw ingredients\n- **Food Recognition** - Recognize prepared foods\n- **Batch Processing** - Multiple items in one image\n- **Allergy Detection** - Alert for user allergies\n- **Confidence Scoring** - Recognition accuracy indicators\n- **Image Enhancement** - Improve recognition quality\n\n### **RECOGNITION FLOW:**\n1. User takes photo or selects from gallery\n2. Image uploaded to backend\n3. AI processes and identifies items\n4. Results displayed with confidence scores\n5. User can edit/confirm results\n6. Items added to inventory\n\n---\n\n## 📷 **6. SCAN MODULE**\n\n**Location:** `lib/features/scan/`\n\n### **PURPOSE:**\nCamera interface and scan result management for food recognition.\n\n### **KEY SCREENS:**\n- `ScanScreen` - Camera interface\n- `AddScanItemScreen` - Manual item addition\n- `ScanConfirmScreen` - Confirm captured images\n- `ScanResultsScreen` - Review recognition results\n\n### **KEY PROVIDERS:**\n```dart\n// Scan results management\nfinal scanResultsProvider = StateNotifierProvider<ScanResultsNotifier, ScanResultsState>\nfinal addScanItemProvider = StateNotifierProvider<AddScanItemNotifier, AddScanItemState>\n```\n\n### **KEY WIDGETS:**\n```dart\n// Scan interface\nScanOptionsModal         // Choose scan type (ingredient/food)\nRecognizedItemCard       // Display recognized items\nQuantitySelector         // Set item quantities\n```\n\n### **SCAN TYPES:**\n```dart\nenum ScanItemType {\n  ingredient,    // Raw ingredients\n  food,         // Prepared foods\n}\n```\n\n### **SCAN WORKFLOW:**\n1. User selects scan type (ingredient/food)\n2. Camera interface opens\n3. User captures image(s)\n4. Images sent for AI recognition\n5. Results displayed for confirmation\n6. User edits quantities/details\n7. Items added to inventory\n\n---\n\n## 🌱 **7.
